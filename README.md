# Codex 不用信用卡怎么订阅：免费额度、苹果礼品卡和微信付款这几条路，价格与限制一次说清

搜这个问题的人，情况基本一样：ChatGPT 账号已经有了，Codex 也想用，卡在最后一步——付款页面只认 Visa / Mastercard，手里的银联卡怎么填都不行。

Codex 本身不是一件可以单独购买的「东西」。它是 OpenAI 的编程智能体，绑定在 ChatGPT 套餐上，桌面 App、云端任务、CLI 都共用同一套登录。所以「订阅 Codex」这句话真正的意思，是**把你账号所在的那档 ChatGPT 套餐开起来**。明白这一点之后，可选路径就清晰了：要么想办法拿到一档带 Codex 的套餐，要么先用不花钱的额度顶着。

下面按「花多少钱、麻不麻烦、稳不稳」三条线，把能走通的路排一遍。

## 先看清楚：Codex 对应的是哪一档套餐

OpenAI 把 Codex 开放给所有 ChatGPT 套餐，区别只在额度。以下价格来自 ChatGPT 官方定价页的公开信息：

| 套餐 | 月费 | Codex 可用情况 |
| --- | --- | --- |
| Free | 免费 | 支持，但额度极少，只够试手 |
| Go | $8 | 有 Codex 访问，在 Codex 里和 Free 差别不大 |
| Plus | $20 | 完整的 Codex 访问，日常开发够用 |
| Pro 5x | $100 | Plus 的 5 倍额度，中高强度使用 |
| Pro 20x | $200 | Plus 的 20 倍额度 |
| Business / Enterprise | 按席位计费，需联系销售 | 面向团队和组织 |

给自家用的开发者，起点基本就是 Plus。Plus 之上要不要加钱，判断标准很简单：你是不是**已经**连续遇到额度用完、被迫等重置。还没有遇到，就别急着上 Pro。

另外有一条容易被忽略的信息：OpenAI 官方帮助中心写明，美国和加拿大经过验证的在校大学生可以领 100 美元、也就是 2500 点的 Codex 额度，额度发到自己的 ChatGPT 账号上，12 个月后过期。如果你符合条件，先领这个，比研究怎么付钱划算得多。

## 路线一：完全不花钱，用 ChatGPT 账号登录 Codex CLI

这是最省事的一条，因为 Codex 的登录走的是 ChatGPT 账号，不是 API key，整个过程中不需要填任何银行卡。

安装只有一行：

bash
npm install -g @openai/codex
# 或者
brew install codex


装完用 `codex --version` 确认一下版本，公开资料里提到 0.28.0 以上才会在模型选择器里列出新模型。然后直接运行 `codex`，浏览器会弹出一个登录页，用你平时登录 ChatGPT 的邮箱走 OAuth 就行。如果是在没有图形界面的服务器上，用设备码流程：

bash
codex login --device-auth


终端会给一个短链接和一段码，在另一台设备上打开、粘贴、确认，服务器那边的登录就完成了。会话会被缓存，之后启动不用重复登录。会话里想看还剩多少额度，敲 `/status`。

**代价是额度。** 据公开报道，OpenAI 在发布 GPT-5.5 时把 Codex 一并开放给了包括 Free 和 Go 在内的所有套餐，但明确写成「限时」。这句话的意思是：这条路现在能用，什么时候收紧不确定。真打算拿 Codex 干活的话，别把工作流建在它上面，当作试用更合适。

顺带说一句，指望用 API key 绕开付款是走不通的——API 是另一套计费体系，要单独充值，对没卡的人来说反而更绕。

## 路线二：支付宝买苹果礼品卡，走 iOS 内购

如果你手边有 iPhone 或 iPad（二手的也行，能正常打开 App Store 就可以），这条路不需要境外银行卡，全程在支付宝里完成。

大致的流程是：

1. 准备一个海外区 Apple ID，注册时选美国或新加坡，不需要绑定国内手机号；
2. 在苹果设备上退出国内 Apple ID，登录这个海外区账号；
3. 打开支付宝，把定位切到「美国旧金山」，界面会转成国际版，在功能区里能找到苹果礼品卡，买一张 20 美元的；
4. 复制兑换码，进 App Store 点头像 →「兑换礼品卡或代码」，充值到 Apple ID 余额；
5. 打开 ChatGPT App，登录你的账号，在设置里订阅 Plus，付款方式选 Apple ID 余额。

这条路的好处是订阅走的是正规内购渠道，账单在自己的 Apple ID 里能查到，续费也自动。麻烦的地方在于切换账号：不只是 App Store 要切，订阅期间最好别频繁来回切区，否则容易触发风控。另外礼品卡本身是不可退的，充进去的钱只能在 Apple 生态里花。

有人会顺带用**土耳其区 Apple ID + 该区礼品卡**来压低单价，公开资料里提到过这种做法，但它来自第三方经验，不是 OpenAI 或 Apple 的官方说明。跨区账号、礼品卡余额、汇率和风控策略都可能变动，存在充值失败、订阅失败、余额无法退款的风险。真要试，先用小额验证，别一上来就充几个月。

## 路线三：用第三方平台，微信或支付宝直接付款

如果你既不想买礼品卡，也不想折腾 Apple ID 切区，剩下的就是第三方订阅平台这条路。它的原理很简单：平台接单，用它可以动用的支付通道帮你在你的账号上把套餐开起来。你付人民币，它付美元。

BeWild.ai（也叫 WildAI）是这一类里比较常被提起的一个，在国内用户里知名度主要来自两件事：支持微信、支付宝付款，以及不用办国际信用卡。需要说清楚的是，**它不卖「Codex 订阅」**，卖的是 ChatGPT Plus、Pro 和 Claude Pro 这类上游套餐，你买到的是账号上的付费状态，Codex 自然跟着可用。

流程大致是：注册账号 → 选服务和时间长度 → 提供账号的登录授权（公开教程里写的是复制页面信息、粘贴回平台，本质是 session 凭据）→ 微信或支付宝扫码付款 → 等平台把订阅挂上去。已经有 ChatGPT 账号、只是想解决支付问题的用户，比自己从头折腾虚拟卡直接。

## 三条路横向比一比

| 方案 | 要不要信用卡 | 成本 | 稳定性 | 适合谁 |
| --- | --- | --- | --- | --- |
| Codex CLI 用 Free / Go 账号登录 | 不要 | $0 | 额度少，且官方标注为限时 | 先摸清楚 Codex 值不值得付费 |
| 海外 Apple ID + 礼品卡内购 | 不要 | 官方原价 $20/月，另加礼品卡汇率损耗 | 走正规内购渠道，账单可查 | 有苹果设备、愿意切区的人 |
| 第三方平台（如 BeWild） | 不要 | 约 $22–26/月 | 依赖平台通道和售后 | 只想扫个码把事办完的人 |

## 走第三方渠道之前，有几件事得先知道

这部分不是劝退，是让你别把预期设错。

**第一，这不是官方渠道。** 账号是你的，但付款环节经手了第三方。公开论坛上有用户反映，2026 年 4 月有平台给出的订阅实际走的是 iOS / Android 内购通道，这类通道的稳定性不由你控制。也有用户记录到订阅掉线、续费失败、新订单未生效的情况。同时，也有用户记录到客服最终为异常订单办理了退款。评价两极，说明它的体验本来就参差。

**第二，需要交出 session 凭据。** 平台能帮你续订，前提是它能替你登录。这意味着你的登录凭据会经过第三方服务器。如果这个账号上还有别的重要信息，自己掂量。

**第三，别一次买太久。** 单月套餐虽然单价最贵，但试错成本最低。先买一个月，确认订阅真的挂上去了、续费节点能正常走，再考虑三个月。

**第四，保留订单和聊天记录。** 出问题的时候，订单号、付款凭证、客服沟通记录就是你申请退款的依据。

## 几个常被问到的问题

**Codex 免费版到底能不能用？**
能，但额度很紧，只适合验证「这个东西我用不用得上」。真要写项目，Free 和 Go 都不够。

**我已经买了 ChatGPT Plus，还要另外买 Codex 吗？**
不用。Codex 包含在套餐内，同一个 ChatGPT 账号登录即可，桌面 App、云端任务、CLI 通用。

**第三方平台能不能帮我开 Pro？**
公开记录里出现过 Pro 20x 的订单和续费失败案例，说明这项服务确实存在过。有没有、多少钱，以平台当前页面为准，别按旧文章里的价格下单。

**订阅掉了怎么办？**
先确认自己的 ChatGPT 账号状态和账单，再联系平台客服。如果订单仍在有效期内、订阅却掉了，按平台规则申请退款或补挂。等待期间别急着重复下单，重复订单叠加反而更难处理。

## 怎么选

如果只是想确认 Codex 好不好用，直接用免费额度那套 CLI 流程，一分钱不花，也不用研究付款。确认要长期用了，有苹果设备就走礼品卡，实在不想折腾再上第三方平台，先按月买。

顺序清楚之后，这个问题其实不复杂：没有信用卡并不会挡住你，挡住你的只是选错了入口。
